# Roamie 產品架構：Free 與 Plus

> **核心理念**
>
> - **Roamie Free 必須完整可用** — 使用者能真正完成一次旅行規劃。
> - **Roamie Plus 的價值不是「解鎖功能」** — 而是 **「Roamie 越來越懂你」**。
> - Plus 不是增加 AI 次數；Plus 是專屬的個人化旅行顧問。

---

## 一、Roamie Free

### 定位

第一次接觸 Roamie 的使用者。可完整體驗產品核心價值，並真正完成一次旅行規劃。

### 完整可用功能

| 類別 | 功能 |
|------|------|
| AI | 對話、地點推薦、行程規劃 |
| 探索 | 景點搜尋、餐廳搜尋、附近探索 |
| 情境 | 天氣推薦、心情推薦、穿搭建議 |
| 收藏 | 收藏地點、收藏行程 |
| 導航 | 地圖導航、Google Maps 導航 |
| 分享 | 行程分享 |

**不限制**：核心功能、導航、規劃行程。Free 不應以「次數」或「功能鎖」阻擋完成旅行。

### 首頁（Free）

| 區塊 | 說明 |
|------|------|
| 今日天氣 | 當地天氣與穿搭／出門建議 |
| 今日心情 | 依心情調整推薦方向 |
| 附近推薦地點 | 依位置與情境推薦 |
| 與 Roamie 聊聊 | 進入 AI 對話 |
| Plus 功能介紹卡 | 說明 Plus 如何「更懂你」，非功能解鎖 |

### 聊天上下文（Free）

Free 保留 **當次有效** 的上下文，不建立長期記憶：

| 層級 | 內容 | 生命週期 |
|------|------|----------|
| 聊天室上下文 | 當前對話 thread | 本次聊天 |
| 本次旅行上下文 | 目的地、天數、預算、同伴等 | 本次旅行規劃 |
| 本輪工作記憶 | 當下感受、天氣、時段 | 本輪對話 |

**範例**

```
使用者：我想去大阪五天
AI：開始規劃大阪五天
→ 後續聊天可延續本次旅行內容
```

**離開聊天或重新開始新旅行後**：不保留長期記憶；AI 不引用「你以前…」「依你平常的習慣…」。

### 收藏（Free）

- 可收藏地點、行程
- **AI 不分析收藏內容** — 收藏僅供使用者自行管理與查看

### Free 明確不做

- 長期旅行記憶
- Travel Profile 與偏好分析
- 收藏洞察與偏好標籤
- 今日靈感（主動推薦）
- 行程自動重排
- 旅行前提醒
- Travel Mode
- 深度對話（引用歷史旅行／收藏）
- 行程最佳化建議
- 旅行統計

## 二、Roamie Plus

### 定位

擁有 **專屬旅行顧問** 的感覺。Roamie 會記住使用者，並隨時間越來越懂你的旅行節奏。

### Plus 專屬能力（12 項）

#### 1. 長期旅行記憶

AI 可永久記住（跨旅行、跨裝置）：

- 喜歡的國家／城市
- 喜歡的景點／餐廳類型
- 住宿風格、預算範圍
- 常用交通方式、旅行節奏

例：使用者曾說「不喜歡太趕」「喜歡咖啡廳」「喜歡夜景」→ 未來旅行直接套用。

#### 2. Travel Profile

專屬旅行檔案，首頁可查看：

- 旅行人格
- 偏好分析
- 收藏分析
- 常去城市／國家
- 最愛景點／美食類型

#### 3. 收藏洞察

AI 分析收藏地點與收藏行程，自動產生偏好標籤，例如：

> 最近你特別喜歡：老宅咖啡廳、夜景景點、日式街區

#### 4. AI 主動推薦 — 今日靈感

首頁新增「今日靈感」。AI 依收藏、季節、節慶、天氣、旅行偏好，主動推薦旅行靈感。

#### 5. AI 自動重排行程

遇下雨、休館、塞車、天氣不佳時，AI 主動提供替代景點／路線，並支援一鍵重排。

#### 6. 旅行前提醒

出發前推送：天氣、穿搭、行李、票券、匯率提醒。

#### 7. 旅行中模式 — Travel Mode

旅遊期間自動切換，顯示：附近景點、附近餐廳、備案行程、即時天氣。

#### 8. 深度對話模式

AI 可引用：歷史旅行、歷史收藏、Travel Profile、偏好測驗。

例：「你去年京都旅行收藏很多老宅咖啡廳，這次鎌倉可能也會喜歡這種風格。」

#### 9. AI 行程最佳化

分析交通時間、景點順序、停留時間，自動提出更順路版本。

#### 10. 專屬旅行統計

顯示：規劃行程數、收藏數、城市數、國家數、旅行天數。

#### 11. Plus 專屬首頁

Plus 首頁新增區塊：

- Travel Profile
- 今日靈感
- 收藏洞察
- AI 專屬推薦
- 旅行統計

#### 12. Plus 專屬身份設計

- 首頁顯示 **Roamie Plus** 專屬徽章
- 專屬歡迎語：**「歡迎回來，今天想去哪裡走走？」**

## 三、Free vs Plus 對照

| 維度 | Free | Plus |
|------|------|------|
| 產品承諾 | 完整規劃一次旅行 | Roamie 越來越懂你 |

| 行程規劃 | ✅ 無限制 | ✅ + 最佳化／重排 |
| 天氣／心情／穿搭 | ✅ | ✅ + 旅行前提醒 |
| 收藏 | ✅ 儲存 | ✅ + AI 分析洞察 |
| 導航／分享 | ✅ | ✅ |
| 長期記憶 | ❌ | ✅ |
| Travel Profile | ❌ | ✅ |
| 今日靈感 | ❌ | ✅ |
| Travel Mode | ❌ | ✅ |
| 旅行統計 | ❌ | ✅ |
| AI 次數限制 | ❌ 不作為商業手段 | ❌ |

## 四、AI 上下文模型

```
┌─────────────────────────────────────────────────────────┐
│                    Roamie Plus only                      │
│  長期記憶 · Travel Profile · 收藏洞察 · 偏好測驗結果      │
└─────────────────────────────────────────────────────────┘
                            ↓ 注入 system prompt
┌─────────────────────────────────────────────────────────┐
│              Free + Plus 共用（當次有效）                 │
│  本次旅行上下文 · 本輪工作記憶 · 當下天氣／心情／時段      │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│                    當前聊天 thread                        │
└─────────────────────────────────────────────────────────┘
```

**Free**：僅使用下方兩層；離開聊天或新旅行後，上層不保留。  
**Plus**：三層皆可用；長期記憶持久化於 `conversation_context.plus_memory` 與 profile 相關欄位。

## 七、定價與溝通原則

- **Free**：「你可以規劃旅行。」
- **Plus**：「讓 Roamie 越來越懂你。」
- 升級文案、Plus 介紹卡、App Store 描述皆不得將 Plus 包裝為「解鎖 AI 次數」或「解鎖核心功能」。
- 濫用防護（rate limit）與商業 tier 限制分離；Free 使用者不應因正常使用而觸及「功能鎖」。

## 八、P0 驗證

```bash
npm run verify:plus-personalization
```

- **Prompt 層**：確認 Travel Profile、長期記憶、收藏地點寫入 system prompt；Free 不洩漏 Plus 區塊。
- **Live AI 層**（需 `OPENAI_API_KEY`）：使用者 A（咖啡/慢旅）vs B（購物/夜生活）詢問「大阪五天」，回覆內容必須明顯不同。
